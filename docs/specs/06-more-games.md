# Spec 06: More games

**Status:** Not started

## What to build
Add at least six games, mostly no-device and picture-based (for example Money Bingo, Coin Sort Race, Store Role-Play, Price Is Right guessing, Savings Jar Toss, Scam Detective). Each game uses the existing GAME_FORMATS shape and lists which topics it suits.

## Done when
New games appear in the games library and can be picked by the generator.
