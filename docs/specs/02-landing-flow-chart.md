# Spec 02: Landing page "where do I go?" flow chart

**Status:** Not started

## What to build
A short decision guide on the home page

## Done when
 "I'm a teen volunteer and need a lesson" → Modules or Generator; "I'm a teacher and want a workshop" → Request; "I run the program" → Impact. Built as clickable cards in a simple top-down chart, using the role picker's three roles.:Home page shows the chart above the fold on desktop and as stacked cards on phones. Every path ends at a working link. Picking a path also sets the role.
